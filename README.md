# kotlin-calculator-precourse
## 컨트롤러

---
- 입력받은 명령어의 문자열을 분리한다.
- 문자열이 유효한 입력값인지 확인한다.
  - 유효하다면 기본 구분자를 사용하는지, 커스텀 구분자를 사용하는지 구분한다
  - 유효하지 않다면 계산기를 끝낸다.
- 구분한 문자열의 숫자들을 더한다.
- 더한 숫자를 출력한 후 종료한다.

## 입출력

---
### 입력
- 사용자에게서 입력을 받는다.

## 문자열 분리

---
- 지정된 구분자로 문자열을 분리한 후, 숫자의 리스트를 반환한다.
### 구분자 선택
- 커스텀 구분자를 사용할지, 기본 구분자를 사용할지 선택한다.
- `null` 혹은 빈 문자열인지 확인
- 구분자 사이에 "" 또는 정수 외 문자가 있는지 확인한다.

### 커스텀 구분자
- `//`와 `\n`사이에 구분자를 인식한다
- 해당 구분자로 문자열을 구분해 숫자 리스트를 반환한다.

### 기본 구분자
- `,`, `:`로 문자열을 구분해 숫자 리스트를 반환한다.

## 계산기

---
### 덧셈
- 주어진 숫자리스트들을 더한다.
